# Catalogue of the rules

Generated by `tools/list_rules.py` from the `@rule` marks, the docstrings and the messages of the languages. `confidence` is the default one: a rule may report a lower value for a doubtful case. Where a rule lists several identifiers it may report each of them. The examples go from the wrong text to the corrected text. Most of the rules need the lexicon of their language (`fr.lex`, `en.lex`, `es.lex`); the ones which need the spelling dictionary of the host (`known`) are `fr.participle` and `fr.infinitive`.
