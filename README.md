# grammar-engine

A grammar checker made of independent rules, **one Python file per language**. Offline, no model, no network, standard library only. It finds agreement errors, wrong participles and homophones, missing elisions, fixed errors and more in French, English and Spanish, and it gives for each problem the range of the text, a suggestion, a message in the language of your interface and a confidence. Any program can call it.

Design rule: **no false alarm before more detections.** A rule reports only when the context is unambiguous.

```python
import grammar_engine
checker = grammar_engine.Checker('fr')
for issue in checker.check('Les chat dorment sur le canapé.', ui='en'):
    print(issue.rule, issue.start, issue.end, issue.suggestions, issue.message)
# fr.det_number 4 8 ['chats'] The determiner and the noun do not agree in number: "chats".
```

## Principles

- **Offline and self-contained.** Python 3.9 or later, standard library only. Nothing to install: put the folder on `sys.path`, or run from it.
- **One language = one file.** `grammar_engine/langs/fr.py` holds the class `Grammar` of French: its rules (methods marked `@rule`), its messages, its tagger constraints. A variant (`es_ar.py`) derives from its language.
- **Rules are independent.** Each one looks at tokens and at what the lexicon says about them, and reports with `p.add()`. A rule knows nothing of the others.
- **A lexicon, not code, for morphology.** The rules ask the lexicon for the corrected form; there are no conjugation tables in the rules.
- **Every host.** Import it from Python, run `python -m grammar_engine` from a script, keep `python -m grammar_engine --serve` alive from any language (JSON, one line per request), or embed Python and call `grammar_engine.bridge`.

## Use

**Python**

```python
import grammar_engine
checker = grammar_engine.Checker('es-AR')                       # fr, en, es, es-AR... or your own language
issues = checker.check('Vos tienes razón.', ui='fr')
```

**Command line**: one paragraph per line, JSON out.

```
python -m grammar_engine --lang fr --ui en < text.txt
python -m grammar_engine --lang fr --rules
python -m grammar_engine --lang en --lines file1.txt file2.txt
```

**Server mode**: a process which stays alive, so the lexicon loads once.

```
python -m grammar_engine --serve
{"id": 1, "lang": "fr", "ui": "en", "text": "Les chat dorment."}
{"id": 1, "issues": [{"rule": "fr.det_number", "start": 4, "end": 8, "suggestions": ["chats"], ...}]}
```

Other requests: `{"op": "rules", "lang": "fr"}`, `{"op": "languages"}`, `{"op": "ping"}`. Every field is described in the API reference.

**Bridge** for a program which embeds Python (a C++ or C# program, for example): `bridge.configure(paths_json)`, `bridge.set_known(callable)`, `bridge.check(language, ui, ignored, text)` returns JSON with positions in UTF-8 bytes, `bridge.rules(language)`.

## Result

Each issue has `rule`, `category`, `start`, `end` (code points; server mode adds `byte_start`, `byte_end`, `text`, `paragraph`), `arg`, `suggestions` (an empty one means "delete"), `confidence` and `message`. When two issues overlap, the first one wins. The engine checks one paragraph at a time: split your text at its line breaks.

## Languages and variants

| Code | Language | Lexicon | Rules |
|---|---|---|---|
| `fr` | French | `fr.lex`, from the lexicon of Grammalecte (MPL 2.0) | agreement (determiner and noun, noun and adjective, subject and verb, attribute, participles), tenses and moods after `si` and conjunctions, prepositions, homophones, elision, number words, fixed errors |
| `en` | English | `en.lex`, from Wiktionary through kaikki.org (CC BY-SA 4.0) | determiners, subject and verb, participles, confusions (its/it's, then/than, to/too), `there is` + plural, fixed errors and non-standard forms |
| `es` | Spanish | `es.lex`, from Wiktionary through kaikki.org (CC BY-SA 4.0) | determiner, noun and adjective, subject and verb, participle after `haber`, accents, interrogatives, dequeísmo, impersonal `haber`, subjunctive after verbs of wish |
| `es-AR` | Argentine Spanish | the Spanish one | everything of Spanish, plus the voseo |

The complete list, with an example for each rule, is [docs/RULES.md](docs/RULES.md). Your own languages go in a folder given with `paths=[...]` (or `--path`); a file there replaces a delivered language of the same code.

## Tests

```
python -m unittest discover -s tests
```

The tests have, for each rule, cases which must be reported and cases which must not, and they run the server mode (in process and as a real process).
